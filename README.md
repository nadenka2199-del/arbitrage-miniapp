# Арбитраж: как это устроено

Telegram Mini App для канала @firevadim.

Пять разделов: что такое арбитраж · как проходит сделка · словарь ·
калькулятор издержек · переход в закрытый канал.

## Файлы

- `index.html` — приложение целиком, без внешних библиотек
- `data.json` — все тексты и настройки калькулятора, правятся отдельно от кода
- `preview.html` — та же версия без Telegram SDK, для просмотра в браузере

## Как править тексты

Всё содержимое лежит в `data.json`. Менять там, код не трогать.

## Юридическое

В материалах нет цифр доходности и обещаний заработка.
Дисклеймер про отсутствие индивидуальных инвестиционных рекомендаций —
на главном экране, в `data.json` → `app.disclaimer`.
